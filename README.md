NOME DO PROJETO:Sistema de Organização de uma Biblioteca

NOME DA DEV:Ariely Alencar



DESCRIÇÃO:

O sistema se trata de um software para controle e organização de uma biblioteca, com o objetivo de facilitar o gerenciamento do acervo e dos empréstimos de livros. O sistema será destinado principalmente a bibliotecários, funcionários e usuários da biblioteca.



Entre as principais funcionalidades estão o cadastro e organização dos livros, o cadastro de usuários, o controle de empréstimos e devoluções e o acompanhamento de reservas e atrasos. Dessa forma, o sistema busca tornar a organização da biblioteca mais prática, rápida e eficiente.
